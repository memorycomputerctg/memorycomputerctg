# মেমোরি কম্পিউটার - ওয়েবসাইট

এই ফোল্ডারে হোম পেজ (`index.html`), ৬টি সেবার আলাদা HTML পেজ (`pages/`) এবং প্রতিটির জন্য আলাদা CSS (`css/`) আছে।

## লোকালি দেখতে
VS Code-এ ফোল্ডারটি খুলে `index.html` ফাইলে Right-click > **Open with Live Server**।

## GitHub Pages-এ পাবলিশ করতে
1. GitHub-এ নতুন repository তৈরি করুন।
2. এই ফোল্ডারের সব ফাইল upload করুন।
3. Settings > Pages-এ যান।
4. Source: **Deploy from a branch**, Branch: **main**, Folder: **/ (root)** নির্বাচন করে Save করুন।
5. কিছুক্ষণ পর সাইটের লিংক দেখা যাবে।
